# Security and privacy

Do not post confidential questionnaires, policies, reports, credentials,
customer identifiers, personal data, or vulnerability details in a public
issue.

Pilot requests should contain only the non-sensitive ranges requested by the
issue form. Real pilot evidence must remain on the participant's local machine.

For a vulnerability in this public pilot surface, use GitHub's private
vulnerability reporting page:

https://github.com/antisociale6/security-review-pack-builder/security/advisories/new

This project does not accept security evidence or customer files through
GitHub.
